# CareLink 社内承認用モック

2026年9月9日のヒアリング内容をもとに作成した、介護施設向け入居者情報共有システムの操作モックです。

## 確認方法

`index.html` をブラウザで開いてください。サーバーやインストールは不要です。

## 実装している操作

- 2施設を横断した入居者情報の閲覧
- 氏名・居室・状態による検索と絞り込み
- 入居者ごとの基本情報・最近の記録の確認
- 申し送り・日々の記録の追加（画面内のみ）
- 音声入力の操作イメージ
- 入居者一覧のCSV出力
- 印刷用表示

## 注意事項

- 表示データはすべて架空です。
- 社内説明・要件確認用のモックであり、入力内容は再読み込みすると消えます。
- 認証、データベース、権限管理、AI文字認識は未実装です。
